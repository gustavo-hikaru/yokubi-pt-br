# Fazendo listas com や, とか, など, と, か e に

As listas de itens em japonês são feitas marcando cada item com uma partícula "de lista" específica, que define a natureza da lista. Podem existir listas exaustivas e não exaustivas. Uma lista exaustiva é simplesmente uma lista que diz explicitamente todos os elementos de que é composta. Uma lista não exaustiva é uma lista que dá alguns exemplos ou uma descrição da natureza dos seus elementos, deixando espaço para ambiguidade e indireção. 

"Fui ao shopping com o Paulo e o Frank" é uma lista exaustiva, enquanto "Fui ao shopping com o Paulo, o Frank e o resto da galera" é, por outro lado, uma lista não exaustiva. 

Dependendo da natureza da lista, o último elemento costuma ter a partícula de lista omitida e substituída pela partícula de caso que se aplica à lista inteira.

や faz uma lista **não exaustiva** que dá alguns exemplos de elementos relacionados a uma ideia geral em comum.

<pre>
スプーン<b>や</b>フォークで食べること
Comer com colheres, garfos e coisas do tipo
</pre>

と foi tratado antes como observação lateral, mas aqui o abordaremos explicitamente e o compararemos com や. と faz uma lista "genérica" **exaustiva**. Ele conta todos os elementos da lista.

<pre>
リンゴ<b>と</b>魚<b>と</b>タイヤキ(<b>と</b>)を食べた
Comi maçãs, peixe e taiyaki.
</pre>

Como já mencionado, o último と é opcional e geralmente omitido.

か pode ser usado para dar alternativas. Está mais perto de "ou" do que de "e", embora a distinção às vezes seja confusa.

<pre>
スプーン<b>か</b>フォークで食べる。
Comer com colher ou garfo.
</pre>

とか faz uma lista "vaga". É vaga e, portanto, **não exaustiva**, mas cada item é independente. Os itens não são necessariamente considerados como tendo uma propriedade em comum. 

<pre>
スプーン<b>とか</b>フォークで食べること
Comer com colher, garfo ou algo assim.
</pre>

Ele também pode ser usado para deixar as coisas vagas com um só elemento:

<pre>
例えばデスクトップパソコン<b>とか</b>。
Por exemplo, (tipo) um computador de mesa...
</pre>

Para a surpresa de ninguém, とか é basicamente como と + か. Ele também pode ser usado para listar verbos, muitas vezes para dar opções alternativas. Esta é uma característica distintiva que não existe nas outras partículas de lista desta lição.

<pre>
戦える<b>とか</b>戦えない<b>とか</b>、そういう問題じゃないんだ。
O problema não é se você consegue lutar ou não.

もしかして、付き合ってる<b>とか</b>？
Por acaso vocês estão namorando? (ou algo do tipo)
</pre>

Se a lista for longa demais (mais de 2 ou 3 elementos), é comum usar vírgulas para separar os elementos do meio, sem usar partículas.

など não é tecnicamente uma partícula de lista, mas sim uma partícula de preenchimento que soa como usar "etc." ou "e tal" em português. Ela traz a noção de uma lista de elementos aberta a mais coisas semelhantes. O significado dela é parecido com usar um único や ou とか para dizer que há mais exemplos implícitos, mas não ditos diretamente.

<pre>
完璧な人間<b>など</b>、存在しない。
Coisas como um ser humano perfeito não existem.
</pre>

Essas partículas de lista também são comumente usadas juntas, principalmente com など. O padrão Xや、Y、Zなど é incrivelmente comum, como na frase a seguir:

<pre>
剣<b>や</b>斧<b>、</b>槍<b>、</b>弓<b>など、</b>様々な武器が置かれている。  
Espadas, machados, lanças, arcos e outras armas variadas estavam expostas.
</pre>

Existe outra partícula de lista que às vezes passa despercebida: に. Esta partícula é usada para listar coisas que vêm juntas em um conjunto, ou que o falante está listando uma a uma, como uma cadeia de pensamentos ou uma lembrança ativa.

<pre>
サンドイッチ<b>に</b>ミルク<b>に</b>コーヒー。
Sanduíches... leite... e aí café.
</pre>
