# Contando coisas

Vamos falar agora de contar coisas. Quando você quer dizer uma quantidade, normalmente não pode ter números "soltos" no meio de uma frase. Você precisa combiná-los com uma palavra especial que descreve que tipo de quantidade você está definindo. Essas palavras especiais são chamadas de "contadores", e há **muitos** deles. Alguns são incrivelmente específicos e mudam conforme a coisa que você está contando, mas outros são mais genéricos e as regras não são tão rígidas quanto você poderia ser levado a crer.

É como em português quando não dizemos "cinco gados", e sim "cinco **cabeças** de gado", ou quando falamos "um **copo** de água", "uma **fatia** de pão" ou "um **par** de sapatos". A diferença é que, em português, usamos esse tipo de palavra só com certas coisas, enquanto em japonês isso funciona assim para a maioria das coisas contáveis (para nós, "três pães" ou "dois gatos" não precisam de nada a mais).

O contador mais comum é つ, mas つ também é especial porque não passa de 9. Se você precisa contar mais de 9 coisas "genéricas", precisa usar outro contador (muitas vezes 個, mas você nem sempre pode usar 個 para tudo).

| Número | Leitura                                          |
|--------|--------------------------------------------------|
| 一つ　 | ひとつ                                           |
| 二つ　 | ふたつ                                           |
| 三つ　 | みっつ                                           |
| 四つ　 | よっつ                                           |
| 五つ　 | いつつ                                           |
| 六つ　 | むっつ                                           |
| 七つ　 | ななつ                                           |
| 八つ　 | やっつ                                           |
| 九つ　 | ここのつ                                         |
| 十　　 | とお (isto é uma exceção, não é um contador)     |

Como você pode ver, a pronúncia dessas palavras é incrivelmente chata de aprender. Não tente memorizar tudo isso; apenas saiba que existe e se exponha a isso por meio da imersão. O mesmo vale para muitos outros contadores, como dias (日), meses (月), anos (年), idade (歳/才) etc. As leituras são incrivelmente irregulares.

Uma exceção interessante, a respeito de idade, é que as idades às vezes são informadas diretamente em números, sem contador:

<pre>
ボクはまだ<b>12</b>ですよっ！
Eu ainda tenho só 12!
</pre>

Se você lembra de uma lição anterior, os contadores funcionam como advérbios e podem ir quase a qualquer lugar da frase, como os advérbios. Além disso, assim como os advérbios, os contadores não podem ser marcados por partículas de caso. Mesmo que pareçam substantivos, eles não são substantivos.

<pre>
二人、兄弟がいる
兄弟が二人いる
Tenho dois irmãos
</pre>

Essas duas frases significam a mesma coisa (mas a segunda é mais comum)
