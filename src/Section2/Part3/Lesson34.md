# か, も e でも como modificadores de palavras interrogativas

Além de marcar perguntas, か também pode ser usado para transformar palavras interrogativas em substantivos genéricos. Em português, isso corresponde aos indefinidos "algo", "alguém", "algum lugar" e "algum dia".

|            |                      |
|------------|----------------------|
| なに       | o que                |
| なに**か** | **al**go, alguma coisa |

<br />
 
|            |             |
|------------|-------------|
| だれ       | quem        |
| だれ**か** | **al**guém  |

<br />

|            |                      |
|------------|----------------------|
| どこ       | onde                 |
| どこ**か** | **al**gum lugar      |

<br />

|            |                         |
|------------|-------------------------|
| いつ       | quando                  |
| いつ**か** | **al**gum dia, uma hora |

Muitas vezes なにか é arrastado para なんか:

<pre>
<b>なんか</b>飲む？
Quer beber <b>alguma coisa</b>?
</pre>

Cuidado para não confundir os dois usos a seguir:

<pre>
何<b>が</b>あった？  
O que aconteceu? (lit. O que havia?)

何<b>か</b>あった？  
Aconteceu alguma coisa? (lit. Havia alguma coisa?)
</pre>

Repare que, com palavras interrogativas + か, é comum omitir a partícula が depois delas (何かが → 何か), possivelmente porque é mais fácil de pronunciar. 

De maneira parecida, também podemos usar も para transformar palavras interrogativas em substantivos "inclusivos/exclusivos". Pense em palavras como "nada", "ninguém" e "qualquer coisa" em português. Repare que, assim como no japonês, o português aceita a negação junto com essas palavras: "não tem nada", "ninguém veio". 

|        |                              |
|--------|------------------------------|
| なにも | qualquer coisa / nada        |
| だれも | todo mundo / qualquer um / ninguém |
| どれも | qualquer um deles / nenhum deles |
| いつも | sempre / a qualquer hora / nunca |

<pre>
ここは何<b>も</b>ない  
Aqui não tem <b>nada</b>

誰<b>も</b>が知ってること  
Coisas que <b>todo mundo</b> sabe.

いつ<b>も</b>そんなことを考えてるの？  
Você fica <b>sempre</b> pensando nessas coisas?
</pre>

Observação: no caso de 誰も usado como sujeito em uma afirmação não negativa, o が não pode ser omitido, então vira 誰もが

Existe uma distinção lógica entre "cada coisa em particular" e "qualquer coisa em particular". Ao ligar でも a algumas dessas palavras, você pode dar a elas o sentido de "qualquer" para "qualquer coisa em particular".

<pre>
あんたは誰<b>でも</b>助けるの？  
Você (mesmo) salvaria <b>qualquer um</b> (não importa quem)?

場所はどこ<b>でも</b>いい。  
<b>Qualquer lugar</b> (não importa onde) serve
</pre>
