Bem-vindo ao **Yokubi**!

O Guia de Gramática **Comum**.

*Dedicado a todos que aprendem, querem aprender e **vão** aprender.* 

<div class="warning">
Este guia é uma reescrita completa, com nova organização, do <a href="https://sakubi.neocities.org/">guia de gramática Sakubi</a>. A reescrita completa <b>ainda não terminou</b>, mas o conteúdo principal e o guia estão prontos.
</div>

O Yokubi é um projeto **aberto** e **mantido pela comunidade**. Aceitamos todo tipo de contribuição útil. 

Você é bem-vindo à nossa [comunidade no Discord](https://discord.gg/KZj4dVFDzu) para dar feedback, comentar, revisar ou só bater papo. 

Se quiser contribuir, você pode ver o projeto [no GitHub](https://github.com/Morgawr/yokubi) e abrir issues e pull requests. 

**NÃO** pule a leitura das páginas [Antes de começar](./Before-you-begin.md) e [Preâmbulo](./Preamble.md). Elas explicam como usar este guia.
