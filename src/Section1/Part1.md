# Parte 1: Primeiros passos

Todo mundo tem que começar por algum lugar. Se você não é criança, fica muito mais fácil começar se comparar com o que você já conhece. Vamos fazer isso por um tempo. Não é tão bom quanto ler japonês de verdade, mas vai ajudar bastante.

*(Este guia assume que você conhece os kana, está aprendendo vocabulário por conta própria e tem um dicionário de passar o mouse, como o Yomitan. Se não tem, **[vá resolver isso](https://yomitan.wiki)**.)*
