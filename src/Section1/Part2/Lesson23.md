# Demonstrativos com as palavras こそあど

Demonstrativos são palavras que significam coisas como "este", "esse", "aquele" etc.

Nesse assunto, o japonês se parece bastante com o português: os demonstrativos japoneses se dividem em três "lugares" (perto de quem fala, perto de quem ouve e longe dos dois), assim como o nosso **este / esse / aquele** (e **isto / isso / aquilo**). A diferença é que os demonstrativos japoneses são muito mais regulares. Isso é mais fácil de mostrar do que de explicar, então vamos aos exemplos:

<pre>
<b>こ</b>れ
isto (algo perto de quem fala)

<b>そ</b>れ
isso (algo perto de quem ouve)

<b>あ</b>れ
aquilo (algo longe de quem fala e de quem ouve)

<b>ど</b>れ
qual 

<b>これ</b>はペンです
<b>Isto</b> é uma caneta

<b>それ</b>は猫ですか？
<b>Isso</b> é um gato? (o gato está perto de quem ouve)

<b>あれ</b>は何？
O que é <b>aquilo</b>? (apontando para algo longe de você e de quem ouve)

<b>どれ</b>がいい？  
<b>Qual</b> é bom?
</pre>

As quatro palavras acima são "pronomes demonstrativos". Cada uma delas tem um correspondente natural em português (isto, isso, aquilo, qual). Uma observação: na fala do dia a dia no Brasil, muita gente usa "esse/isso" também no lugar de "este/isto", então a divisão em três que o japonês mantém bem firme é algo que, para nós, às vezes fica meio apagado. No japonês, それ é para coisas perto de quem ouve, e あれ é para coisas longe de quem fala e de quem ouve.

Caso você não tenha notado o padrão, como o título desta lição aponta, às vezes chamamos todos juntos de こそあど, porque eles se diferenciam entre si só pela primeira sílaba kana.

Existe outro grupo de demonstrativos こそあど muito parecido, que funciona gramaticalmente de outro jeito. Em português já fazemos algo semelhante, então vamos primeiro aos exemplos:

<pre>
この&lt;substantivo&gt;
este &lt;substantivo&gt;

その&lt;substantivo&gt;
esse &lt;substantivo&gt;

あの&lt;substantivo&gt;
aquele &lt;substantivo&gt;

どの&lt;substantivo&gt;
qual &lt;substantivo&gt;
</pre>

Essas palavras não podem existir sozinhas e **precisam** se ligar ao substantivo que vem depois delas. O significado é o mesmo do outro grupo, mas o uso é um pouco diferente. 

Imagine que você está segurando um livro e quer dizer "Isto é um livro". "Livro" é o foco da frase, então você diria これは本です. Você está simplesmente dizendo "isto = livro" usando uma cópula. Porém, se você quiser dizer algo **sobre** esse livro, diria この本は面白いです. **Este livro** é interessante. "Este" e "livro" viram uma única unidade. Em português acontece algo parecido: dizemos "**isto** é um livro" (pronome, sozinho), mas "**este livro** é interessante" (acompanhando o substantivo). Em japonês, uma frase usa これ e a outra usa この. 

O mesmo vale para todas as outras palavras こそあど com の. 

Há muitas outras palavras que se encaixam na estrutura こそあど. Não vamos cobrir todas aqui, mas elas costumam ser bem regulares, na medida em que todas seguem a regra:

<pre>
こ = perto de quem fala  
そ = perto de quem ouve  
あ = longe dos dois  
ど = palavra interrogativa
</pre>

A fileira あ é a única com a pronúncia um pouco irregular, mas você vai perceber quando se deparar com elas. Aqui estão alguns exemplos:

|                   |                    |            |         |
|-------------------|--------------------|------------|---------|
| ここ              | そこ               | あそこ     | どこ    |
| aqui (este lugar) | aí (esse lugar)    | ali, lá    | onde?   |

<br />

|                 |                 |                |                  |
|-----------------|-----------------|----------------|------------------|
| こちら          | そちら          | あちら         | どちら           |
| esta direção    | essa direção    | aquela direção | qual direção?    |

<br />

|                 |                |                |                  |
|-----------------|----------------|----------------|------------------|
| こう            | そう           | ああ           | どう             |
| assim (deste modo) | assim (desse modo) | assim (daquele modo) | como? (de que modo?) |

<br />

|           |           |            |            |
|-----------|-----------|------------|------------|
| こいつ    | そいつ    | あいつ     | どいつ     |
| este cara | esse cara | aquele cara | qual cara |

Observação: o grupo こちら também pode ser usado como uma forma polida de se referir a pessoas em um ambiente formal, porque acrescenta indireção. Já o grupo こいつ muitas vezes pode soar rude, então não chame as pessoas de こいつ.

Assim como em português, a distância física não é o único fator determinante para essas palavras. Elas também podem ser usadas para se referir a algo distante no tempo. Podem até ser afetadas pelo grau de familiaridade que o falante e o ouvinte têm com o assunto. Algo mencionado antes em uma conversa pode ser chamado de あの\<coisa\>, mas algo que acabou de ser mencionado tem mais chance de ser その\<coisa\>. Assim como em português às vezes não sabemos se devemos dizer "esse" ou "aquele", até em japonês as pessoas nem sempre concordam, então a distinção nem sempre é rígida nessas situações.
