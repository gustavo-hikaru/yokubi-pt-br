# Revisão dos verbos

Finalmente encontramos todos os radicais básicos dos verbos godan, então este é um bom momento para revisar o que aprendemos. Por favor, não tente memorizar isto. Saber que essas ideias existem já basta. Se seus olhos embaçarem, relaxe. Se você não consegue, siga em frente.

Os nomes dados são só descrições/lembretes simples da forma, e não nomes gramaticais propriamente ditos. O nome em japonês e a respectiva terminologia correta serão apresentados para os curiosos, mas você não precisa lembrar deles. Se um radical ou forma for mencionado no resto do guia, será com o descritor simples em português, e não com o nome japonês.

| Forma           | Nome                         | Termo japonês                                          |
|-----------------|------------------------------|--------------------------------------------------------|
| 書**か**(ない)  | radical negativo             | 未然形 - forma irrealis (não realizada)                |
| 書**き**(ます)  | radical ます                 | 連用形 - forma continuativa                            |
| 書**く**        | forma simples / de dicionário | 終止形 forma conclusiva (predicativa) ou 連体形 forma atributiva (adnominal) |
| 書**け**(る/ば) | radical potencial            | 已然形 forma realis (perfectiva) ou 仮定形 forma hipotética |
| 書**け**        | forma imperativa             | 命令形 - forma imperativa                              |
| 書**こう**      | forma volitiva               | 意向形 - forma volitiva                                |

Lembre-se de que, nos verbos godan, há regras especiais para conjugar as formas passada e て. Por exemplo, na fileira k, き vira い:  

<pre>
書<b>い</b>て
書<b>い</b>た
</pre>

Nos verbos ichidan, o radical continua o mesmo, então é bem mais fácil; basta trocar o る:

<pre>
食べ(ない) forma negativa
食べ(ます) forma ます
食べる forma simples / de dicionário
食べ(られる/れる) forma potencial
食べ(れば) forma condicional / ば
食べ(ろ) forma imperativa
食べ(よう) forma volitiva
食べ(て) forma て
食べ(た) forma passada
</pre>

E os dois verbos irregulares する e くる:

| Forma           | する      | くる     |
|-----------------|-----------|----------|
| negativa        | しない    | こない   |
| radical ます    | し(ます)  | き(ます) |
| simples         | する      | くる     |
| potencial       | できる    | これる   |
| radical ば      | すれば    | くれば   |
| imperativa      | しろ/せよ | こい     |
| volitiva        | しよう    | こよう   |
| forma て        | して      | きて     |
| passado         | した      | きた     |

Além disso, como lembrete, o verbo godan 行く se conjuga de forma irregular como 行って/行った na forma て e no passado.
