# Preâmbulo

Este guia cobre a maior parte da gramática necessária para entender o japonês básico. Ele não vai entrar em muitos detalhes e não cobre muito vocabulário. Se você estiver lendo isto em um navegador, instale uma extensão de dicionário com consulta ao passar o mouse, como o [Yomitan](https://yomitan.wiki/), para consultar facilmente as palavras das frases de exemplo. Algumas palavras são praticamente gramática, porém, então elas aparecem em lições específicas. 

Não há exercícios:

- Treinar habilidades, ou seja, ler uma explicação gramatical e responder perguntas sobre ela, não funciona para aprender um idioma novo.  
- Muita gente foi "envenenada" pela educação moderna e fica com a cabeça fritando se houver qualquer coisa para "trabalhar".  
- Guias de gramática são um péssimo lugar para aprender vocabulário.

Se você quer passar em um exame de proficiência em japonês, como o JLPT, este guia não é voltado para você. Provavelmente você se sairá bem se usá-lo, porque alcançar a proficiência em japonês é tudo o que se precisa para passar nesses exames, mas ele provavelmente vai frustrar suas expectativas a curto prazo. Os tópicos deste guia não estão ordenados por dificuldade no JLPT, e se o seu objetivo é passar nos níveis iniciais em pouco tempo, talvez seja melhor usar materiais específicos para o JLPT.

Nem os melhores linguistas do mundo conseguem explicar ideias simples, como o "tá" de "tá bom" ou o "né" no fim das frases, com menos do que um ensaio impenetrável do tamanho de um livro. Isso não é uma questão de filosofia, é uma questão de explicar o que as coisas realmente significam, ou como funcionam. Explicações simples e incompletas são boas, mas têm furos. Este guia tenta andar na corda bamba e avisar sobre o que ele não consegue explicar, mas é muito difícil. Como leitor, espera-se que você seja flexível e aceite o que está escrito aqui "de cara". Entenda que isto é **como** o japonês funciona, e que perguntar **por quê** muitas vezes não vai levar você a lugar nenhum.

Este guia de gramática faz o melhor possível para dar a você uma exposição básica à gramática japonesa. Ele não consegue **ensiná-la**. Só consegue apresentá-la. O seu trabalho é transformar essa exposição em aquisição. A exposição é só o pé na porta.

E, por favor, se algo for difícil demais, pule. Você não está tentando memorizar algo para passar em uma prova. Você não está tentando memorizar algo para identificar com 100% de precisão quando estiver consumindo japonês.

Você está tentando colocar algo na cabeça. Se não conseguir, tudo bem, você vai pegar isso naturalmente mais tarde.

Não olhe para trás.
