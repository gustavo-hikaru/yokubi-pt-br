# Yokubi (PT-BR)

Tradução e adaptação **não oficial** para o português brasileiro do [Yokubi](https://yoku.bi), um guia de gramática japonesa para iniciantes, de Morg e colaboradores ([repositório original](https://github.com/Morgawr/yokubi)).

Licença: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), a mesma do original. O texto foi alterado em relação ao original; as alterações estão descritas em [`src/Adaptacoes.md`](src/Adaptacoes.md).

Estado: tradução completa das 64 lições e das páginas de apoio, **ainda sem revisão de um falante nativo com formação em japonês**.

Para gerar o site: instale o [mdBook](https://rust-lang.github.io/mdBook/) e Python 3 e rode `mdbook build` (ou `mdbook serve`) na raiz do projeto.

O projeto original: [discord da comunidade](https://discord.gg/KZj4dVFDzu).
